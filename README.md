# Предсказание CaO в карбонатном сырье (известняк, мергель, мел) по химическому составу

Итоговый проект курса Data Science.

## Цели и задачи

**Бизнес-контекст.** Для цементного производства содержание CaO в карьерном сырье определяет
состав сырьевой смеси и коэффициент насыщения. Прямой анализ CaO — отдельное дорогое
измерение, а быстрый анализ примесей (XRF) доступнее.

**Цель.** Построить модель, оценивающую **CaO (масс. %)** по девяти оксидам-примесям:
SiO₂, Al₂O₃, Fe₂O₃, MgO, K₂O, Na₂O, TiO₂, P₂O₅, MnO (без потерь при прокаливании, LOI).

**Задачи:**
1. собрать и очистить датасет из открытой базы;
2. провести EDA и статистический анализ, использовать его выводы в моделировании;
3. сравнить baseline (медиана, физический баланс масс, Ridge) и ML-модели (леса,
   градиентные бустинги, гибрид, стекинг);
4. корректно провалидировать модель на **новых источниках данных**;
5. подготовить модель к использованию: интервалы предсказания, CLI и REST API.

## Данные

*Global whole-rock geochemical database compilation* (Gard et al., 2019, Earth System
Science Data; [Zenodo 10.5281/zenodo.2592822](https://doi.org/10.5281/zenodo.2592822)).
Из ~1 млн анализов отобраны осадочные карбонатные породы (известняк, мергель, мел,
«карбонат»; доломиты и обломочные породы исключены). Итог — **3208 проб из 88 публикаций**:

| Класс | Проб |
|---|---|
| limestone | 1961 |
| calcareous_other | 1218 |
| marl | 25 |
| chalk | 4 |

Особенности: пропуски в малых оксидах (Na₂O 31 %, Fe₂O₃ 21 %), значения ниже предела
обнаружения (заменяются на ½ предела), 54 % проб из одной публикации, ~55 % из США.
Сырые файлы (~340 МБ) скачиваются скриптом автоматически и в репозиторий не входят;
готовый датасет лежит в `data/carbonates_cao.csv`.

## Этапы работы

1. **Сбор и очистка** — `src/build_dataset.py`: фильтрация пород, обработка пределов
   обнаружения, единая форма железа, контроль суммы оксидов и границ CaO, дубликаты.
2. **EDA и статистика** — `notebooks/01_eda.ipynb`: пропуски, распределения, тесты
   Шапиро–Уилка, корреляции Спирмена, VIF, Краскел–Уоллис и Манн–Уитни. Главные
   выводы: CaO почти однозначно определяется балансом масс (ρ = −0.94 с суммой остальных
   оксидов), источники данных сильно различаются (p ≈ 10⁻⁸⁶), метка типа породы CaO
   статистически не различает (p = 0.71).
3. **Моделирование** — `notebooks/02_modeling.ipynb`: отложенные *группы*, повторная
   групповая CV, статистическое сравнение моделей с бутстрэпом по группам, Optuna, анализ
   ошибок, SHAP, conformal-интервалы.
4. **Упаковка** — `models/cao_model.joblib`, `app/predict.py` (функция и CLI),
   `app/api.py` (FastAPI), тесты `tests/`.

### Ключевые решения

* **Физический baseline** `CaO = (100 − 2.09·MgO − Σ прочих оксидов) / 1.785` — из баланса масс
  (потери при прокаливании ≈ CO₂ карбонатов). Он объясняет ~92 % дисперсии, поэтому ML
  сравнивается с ним, а не только с медианой.
* **Групповая валидация.** Пробы одной публикации похожи друг на друга, поэтому
  `GroupKFold` по источнику; крупнейшая публикация дополнительно делится на 8
  пространственных блоков.
* **Признаки:** сумма оксидов, стехиометрическая оценка CaO, log(SiO₂/Al₂O₃), доля MgO,
  число пропусков. Метки породы и LOI в модель не входят.

## Результаты

**Групповая CV** (повторная, `GroupKFold` по источникам, `reports/cv_metrics.csv`):

| Модель | MAE | RMSE | R² |
|---|---|---|---|
| Медиана | 10.62 | 12.72 | −0.06 |
| Физический баланс масс | 2.05 | 3.70 | 0.910 |
| Ridge (9 оксидов) | 2.04 | 3.32 | 0.928 |
| LightGBM | 2.03 | 3.39 | 0.925 |
| CatBoost | 1.94 | 3.33 | 0.927 |
| **Стекинг** | **1.83** | **3.21** | **0.933** |

**Отложенные источники** (`reports/holdout_metrics.csv`):

| Модель | MAE | RMSE | R² |
|---|---|---|---|
| Медиана | 16.03 | 19.80 | −0.40 |
| Физический баланс масс | 2.26 | 3.71 | 0.951 |
| Ridge (9 оксидов) | 2.15 | 3.71 | 0.951 |
| LightGBM | 2.85 | 4.61 | 0.924 |
| CatBoost | 2.98 | 4.78 | 0.919 |
| Стекинг | 2.39 | 3.86 | 0.947 |

**Вывод.** Задача почти линейна (закон сохранения массы), поэтому простые модели очень
сильны. Все модели намного лучше медианы. В групповой CV стекинг лучший, но выигрыш над
Ridge и физической формулой небольшой. На отложенных источниках ансамбль их не
превосходит: Ridge и формула не хуже, а одиночные бустинги чуть хуже обобщаются на новые
источники. Для продакшена достаточно Ridge или физической формулы; стекинг даёт
устойчивость в CV и используется как итоговая модель с conformal-интервалами.
Итоговая модель выбрана по CV на обучающей части (не по тесту), поэтому метрики на
отложенных источниках — честная оценка для новых источников. 90 % интервал (±4.31 п.п.)
на новых источниках покрывает 82.7 % проб — то есть чуть оптимистичен.

Графики — в `reports/figures/`, подробная интерпретация — в конце `02_modeling.ipynb`.

## Структура

```
data/carbonates_cao.csv     # готовый датасет
src/                        # сборка данных, признаки, модели и валидация
notebooks/                  # 01_eda, 02_modeling (с выполненными ячейками)
notebooks_src/, tools/      # исходники ноутбуков в .py и сборщик

reports/                    # метрики и графики
```

## Воспроизведение

```bash
pip install -r requirements.txt
python -m src.build_dataset            # скачает базу и пересоберёт датасет
python tools/make_notebook.py notebooks_src/01_eda.py notebooks/01_eda.ipynb
python tools/make_notebook.py notebooks_src/02_modeling.py notebooks/02_modeling.ipynb
pytest -q
```

Запуск из корня репозитория (`PYTHONPATH=.`). Все сиды зафиксированы.

## Ограничения

Данные географически смещены (США), мергелей всего 25, мела 4; LOI, влажность и метод
анализа неизвестны. На конкретном карьере модель нужно проверить по локальным
анализам или дообучить.
